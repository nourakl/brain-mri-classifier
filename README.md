# Brain Tumor MRI Classifier

A deep-learning web app that classifies brain MRI scans into four classes: **glioma**, **meningioma**, **pituitary tumor** and **no tumor**. An LLM assistant (Gemini or OpenAI) explains the result in plain language and answers follow-up questions.

Built for the Big Data course (May–Jun 2026).

## Results

- Best model: **ResNet50V2** (transfer learning), **88% accuracy** on a balanced 1,600-image test set
- Per-class F1 between 0.83 and 0.94; recall of 0.98 on *no tumor* and 0.96 on *pituitary*
- Benchmarked against a custom baseline CNN, EfficientNetB0 and DenseNet121

## Features

- Upload an MRI scan → predicted class with per-class probabilities
- Patient-friendly explanation generated by an LLM, with a built-in fallback description if no API key is set
- Follow-up chat that keeps the scan result as context
- Custom dark Gradio interface

## Tech stack

Python · TensorFlow / Keras · Gradio · Pillow · NumPy · Google Gemini API (optional OpenAI)

## Run it locally

```bash
pip install -r requirements.txt

# optional – enables the LLM explanations and chat
export GEMINI_API_KEY="your-key-here"        # Windows: set GEMINI_API_KEY=your-key-here

# path to the trained Keras model (defaults to ./brain_tumor_clean.keras)
export MODEL_PATH="brain_tumor_clean.keras"

python app.py
```

Then open http://127.0.0.1:7860.

The trained model file (`brain_tumor_clean.keras`) is not included in this repository because of its size. Place it next to `app.py` or point `MODEL_PATH` at it.

## Input

RGB images resized to 224 × 224, scaled to [0, 1].
